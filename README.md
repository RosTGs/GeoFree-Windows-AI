# GeoFree Windows AI

Настройка доступа к нейросетям через файл hosts в Windows 10/11.
Скрипт получает адреса из GeoHideDNS, перебирает кандидаты и проверяет HTTPS-соединение с ChatGPT, OpenAI API, Claude и Gemini.

## Запуск

1. Нажмите зелёную кнопку **Code** вверху страницы репозитория и выберите **Download ZIP**.
2. Нажмите правой кнопкой на архив и выберите «Извлечь всё».
3. Откройте полученную папку.
4. Нажмите правой кнопкой на `START-GEOFREE-AS-ADMIN.bat` и выберите «Запуск от имени администратора».
5. Подтвердите запрос Windows и дождитесь завершения проверки.
6. После сообщения `GeoFree AI access is ready` перезапустите браузер и приложения нейросетей.

## Проверка и удаление настроек

`CHECK-GEOFREE.bat` показывает записи hosts и текущие адреса сервисов.

`REMOVE-GEOFREE-AS-ADMIN.bat` удаляет управляемый блок GeoFree. Перед изменением hosts скрипты создают резервную копию рядом с системным файлом.

## Особенности

Список доменов включает ChatGPT, OpenAI API, Claude, Anthropic API, Gemini, Google AI Studio, Copilot, Grok и ElevenLabs.

HTTPS-проверка подтверждает получение ответа сервера, включая ответы с кодами ошибок. Работу входа в аккаунт и генерации проверяйте в приложении после настройки. Доступность зависит от сети и серверов стороннего провайдера.
