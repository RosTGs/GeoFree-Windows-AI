# Запуск на Mac

Скрипты используют штатные Bash и curl macOS и рассчитаны на Apple Silicon, включая MacBook M1.

1. На главной странице репозитория нажмите **Code → Download ZIP**.
2. Откройте архив двойным щелчком в Finder и найдите папку `mac`.
3. Откройте **Терминал** через Spotlight: `Command + пробел`, введите «Терминал», нажмите Enter.
4. Введите `cd ` с пробелом, перетащите папку `mac` в Терминал и нажмите Enter.
5. Выполните команду:

```bash
/bin/bash ./run-geofree.command
```

6. Введите пароль администратора и нажмите Enter. Терминал скрывает символы пароля при вводе.
7. Дождитесь сообщения `GeoFree is working` и перезапустите браузер и приложения нейросетей.

Для повторного запуска используйте ту же команду из папки `mac`.

## Проверка

```bash
/bin/bash ./check.sh
```

Скрипт показывает запись hosts и текущий адрес каждого сервиса. Автоматическая настройка проверяет HTTPS-ответы ChatGPT, OpenAI API, Claude и Gemini. HTTP-коды ошибок также считаются ответом сервера. Вход в аккаунт и генерацию проверьте в приложении.

## Удаление настроек

```bash
sudo /bin/bash ./uninstall.sh
```

Команда удаляет управляемый блок GeoFree и обновляет DNS-кэш. Перед изменением создаётся резервная копия `/etc/hosts.backup.YYYYMMDD_HHMMSS`.

## Особенности

Настройка охватывает ChatGPT, Claude, Gemini, Copilot, Grok, ElevenLabs и связанные API. При применении скрипт заменяет блок GeoFree и строки hosts с целевыми доменами.

Адреса поступают из GeoHideDNS. Кандидат выбирается после совпадения DNS-адреса и получения четырёх HTTPS-ответов. После исчерпания списка последний адрес остаётся в hosts; для удаления блока выполните команду выше. Доступность зависит от сети и серверов провайдера.
